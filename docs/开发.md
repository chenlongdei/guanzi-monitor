# 开发说明

观自行深监控台的代码结构和开发方式。用户安装和使用见根目录 README。

## 启动

- 开发时：`cd backend && uv venv --python 3.11 .venv && uv pip install -e . --python .venv/bin/python`，再 `.venv/bin/guanzi-monitor`
- 用户安装走 `scripts/start.sh`（装到 `~/.guanzi-monitor/venv`，可编辑安装，git pull 后直接生效）
- 演示模式（假数据，不联网，不花钱）：`.venv/bin/guanzi-monitor --demo`
- 换保存位置：`.venv/bin/guanzi-monitor --data <目录>`，设置会被记住

数据保存在 `~/.guanzi-monitor/config.json` 的 `data_root` 指向的目录（默认 `~/观自行深监控台/`）：

```
采集/
├── _工作台/workbench.db         索引、数据快照、来源、监控、任务（SQLite）
├── 抖音/博主/<博主>/<日期>_<标题>_<ID>.md     逐字稿（和 dei-capture 同一套目录）
├── 小红书/博主/…
└── 视频号/博主/…
```

保存位置设在外接盘而外接盘没插时，启动会直接报错退出，不会在别的地方新建目录。

## 文风 DNA（博主页）

博主页「文风 DNA」卡片：选最近 N 条或全部 → 估费确认 → 后台跑，2–6 分钟出报告。

- 材料：逐字稿优先，没有就用文案；可勾「先转写没逐字稿的」。超过约 60 万字只装入最新的，报告里写明。
- 程序先算「量化底稿」（句长分布、文案标点、人称/确定性/指令/口头禅词频、高频串），和原文一起交给 Claude，模型的数字以底稿为准。逐字稿的标点是语音识别加的，不当作者习惯。
- 报告：哲学底层 → 意识形态与权力 → 修辞论证 → 身体情感美学 → 内部矛盾 → 六维评分 → 三位作者对比 → 仿写提示词 → DNA 指纹。报告页可一键复制仿写提示词。
- 存放：数据库 `style_reports` 表 + `采集/<平台>/博主/<博主>/_文风DNA_<日期>_<N>条.md`。
- 设置页「AI 分析」：填 Anthropic API Key，选模型（默认 Opus 5.5）和思考深度。30 条约 $0.7。
- 提示词在 `backend/guanzi_monitor/services/style.py` 的 `SYSTEM`，要改分析框架改这里。

## 结构

```
backend/guanzi_monitor/
  providers/   渠道适配层：monid.py（主力）、tikhub.py（备用）、sph_map.py（视频号字段）、demo.py
  services/    links（链接识别）、store（入库去重规则）、transcribe（转写 + 写 md）、style（文风 DNA）
  jobs.py      单条 / 关键词 / 博主 / 转写 / 刷新，后台线程跑
  scheduler.py 监控定时（工作台开着时每 30 秒检查一次）
  app.py       API + 前端静态文件
web/           React 前端，用 `pnpm build` 打包到 backend/guanzi_monitor/web
probe/         接口验证脚本、样例返回、抖音关键词对比报告
```

## 改前端

```
cd web && pnpm dev           # 开发地址 http://localhost:5178，/api 代理到 8765
bash scripts/build.sh        # 打包进后端 + 检查没有 Key / 个人路径，提交前必跑
```

前端打包结果 `backend/guanzi_monitor/web/` 要提交进仓库：用户安装时不需要 Node。

## 发版

改完 `bash scripts/build.sh` → 提交 → push。依赖有变化时改 `backend/pyproject.toml`，用户下次启动会自动重装；版本号同时改 `pyproject.toml` 和 `db.py` 的 `VERSION`。
