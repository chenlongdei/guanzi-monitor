# 本地接口

`$URL` = `start.sh --status` 返回的 `url`（默认 http://127.0.0.1:8765）。请求体都是 JSON：`curl -s -X POST $URL/api/... -H 'content-type: application/json' -d '{...}'`。
平台代号：`douyin` 抖音、`xhs` 小红书、`sph` 视频号。

## 设置

| 接口 | 说明 |
|---|---|
| `GET /api/settings` | 当前设置。Key 只返回 `{set, tail}`；`ready` = 数据渠道 Key 是否已填；`data_root` 保存位置 |
| `PUT /api/settings {"monid_token": "..."}` | 改设置。Key 字段传空字符串表示不改 |
| `POST /api/settings/test {"name": "monid"}` | 测试连接，`name` 可选 `monid` / `tikhub` / `dashscope`，Monid 会返回 `balance_usd` |

## 报价

`POST /api/estimate {"kind": "keyword", ...与创建任务相同的参数}` → `{items, calls, usd, asr_cny, total_cny, need_confirm}`（`need_confirm` 为 true 时必须先问用户）

## 创建任务（都返回 `{"job_id": n}`）

**单条**：`POST /api/jobs/single`
```json
{"text": "一段或多段分享文案 / 链接，混在一起也行", "transcribe": true}
```

**关键词**：`POST /api/jobs/keyword`
```json
{"platform": "douyin", "keyword": "AI 副业", "sort": "relevance", "days": 7, "limit": 20, "transcribe": false,
 "opts": {"engine": "index", "label_type": 1, "enrich": true}}
```
- `sort`：`relevance` 综合 / 指数排名，`likes` 最热，`newest` 最新
- `days`：抖音指数只支持 0 / 3 / 7 / 30；其他平台 0 / 1 / 7 / 30 / 180（0 = 不限）
- `opts.engine`（只抖音）：`index` 抖音指数视频搜索（默认，便宜、一次几百条、带爆款标签），`search` 抖音站内搜索
- `opts.label_type`（只抖音指数）：1 低粉爆款、2 高完播率、3 高涨粉率、4 高点赞率
- `opts.enrich`：抖音指数和视频号默认逐条补评论 / 收藏 / 分享（每条多 ~$0.0012），`false` 可省钱

**博主**：`POST /api/jobs/blogger`
```json
{"input": "主页链接 / 分享文案 / sec_uid", "limit": 30, "transcribe": false}
```

**转写已有内容**：`POST /api/jobs/transcribe {"content_ids": [1, 2]}`
**刷新数据**：`POST /api/jobs/refresh {"content_ids": [1, 2]}`

## 查任务

| 接口 | 说明 |
|---|---|
| `GET /api/jobs/{id}` | `status`：queued / running / done / partial（部分失败）/ failed / canceled；`done` `failed` `new_count` `cost_usd` `log`（每步日志，失败原因在里面）；关键词任务带 `results` |
| `GET /api/jobs?kind=keyword&limit=10` | 最近任务 |
| `POST /api/jobs/{id}/cancel` / `retry` | 取消 / 重试 |

## 内容与博主

`GET /api/contents`，参数：
- `platform`、`q`（搜标题和逐字稿）、`author`（博主 id）、`keyword`（某关键词搜到的）、`source`（`single` / `keyword` / `blogger`，监控采到的也算在 keyword / blogger 里）
- `transcript`（`done` 只看有逐字稿的）、`sort`（`first_seen` / `published_at` / `likes` / `comments` / `saves` / `shares`）、`order`（`desc` / `asc`）、`page`、`size`

返回 `{items, total}`。每条有：标题、链接、作者、发布时间、点赞 / 评论 / 收藏 / 分享、`transcript_status`、`transcript_path`（逐字稿 md 的本地路径），以及 `ins` 指标（见 SKILL.md「读懂数据」）。

| 接口 | 说明 |
|---|---|
| `GET /api/contents/{id}` | 单条详情，含逐字稿全文、数据变化快照、它是从哪些任务来的 |
| `GET /api/contents/export?keyword=X` | 下载 Excel（也支持 `platform`、`author`、`ids=1,2,3`） |
| `GET /api/authors?platform=douyin&q=昵称` | 博主列表 |
| `GET /api/authors/{id}` | 博主详情：粉丝、作品、基线（他平时的收藏率、转发率等中位数） |
| `POST /api/authors/{id}/fetch {"limit": 30}` | 再拉一次这个博主的作品 |

## 监控

| 接口 | 说明 |
|---|---|
| `GET /api/monitors` | 全部监控 |
| `POST /api/monitors` | 新建，见下 |
| `PATCH /api/monitors/{id}` | 改 `interval_hours` `max_items` `auto_transcribe` `enabled` |
| `DELETE /api/monitors/{id}` | 删除 |
| `POST /api/monitors/{id}/run` | 立刻跑一次 |

```json
{"kind": "keyword", "platform": "douyin", "target": "AI 副业", "label": "AI 副业",
 "params": {"days": 7, "opts": {"engine": "index"}}, "interval_hours": 24, "max_items": 20, "auto_transcribe": false}
```
博主监控：`"kind": "blogger", "target": "<博主 id>"`，博主要先用博主任务采进库，从 `/api/authors` 拿 id。

监控只在监控台开着时跑；电脑关机或合盖期间错过的，下次打开会补跑一次。
