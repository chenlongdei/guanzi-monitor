# 费用（按实测单价估算）

| 操作 | 大约花费 |
|---|---|
| 单条抖音 / 小红书 | $0.001–0.002 |
| 抖音关键词 20 条（抖音指数 + 补全评论 / 收藏 / 分享） | ~$0.025 |
| 抖音关键词 20 条（不补全） | ~$0.001 |
| 博主最新 30 条 | ~$0.01–0.03 |
| 视频号单条 | ~$0.01 |
| 逐字稿 | 阿里云 ¥0.288 / 小时音频（1 分钟视频约 ¥0.005） |
| 每天盯 5 个博主 + 3 个关键词 | 约 $3–5 / 月 |

- 开始采集前，网页会显示预计花费；超过 20 条会先让你确认（设置里可以改）
- 「总览」页能看到本月花了多少；「任务记录」里每个任务都有花费
- 失败的请求一般不扣费
