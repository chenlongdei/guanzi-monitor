# 排错

先看两样东西：
```bash
bash "<skill>/scripts/start.sh" --status
tail -50 ~/.guanzi-monitor/server.log
```
Windows：`%USERPROFILE%\.guanzi-monitor\server.log`（前台运行时日志直接在黑窗口里）。

## 安装

| 现象 | 原因与处理 |
|---|---|
| Mac 双击 `.command` 提示「无法打开，来自身份不明的开发者」 | 右键 → 打开 → 再点「打开」；或终端运行 `xattr -dr com.apple.quarantine <skill 文件夹>` |
| 卡在「安装 uv」 | 访问不了 astral.sh。脚本会自动改用 pip 装（清华 → 阿里云 → 官方源依次试），并到 pip 的安装位置找 uv（Windows 是 `%APPDATA%\Python\Python3xx\Scripts\uv.exe`）。还不行就手动：Mac `python3 -m pip install --user uv -i https://pypi.tuna.tsinghua.edu.cn/simple`；Windows `python -m pip install --user uv -i https://pypi.tuna.tsinghua.edu.cn/simple`（需要先装 Python） |
| Windows Git Bash 报 `checksum mismatch`，然后 `uv: command not found` | 旧版脚本用 install.sh 装 uv，校验文件带 CRLF。`git pull` 更新后重试，新版在 Windows 上走 PowerShell 安装器 |
| 卡在下载 Python | 脚本默认走 npmmirror 镜像；公司网络拦截时换个网络，或先自己装 Python 3.11+，uv 会直接用 |
| 依赖下载慢 / 超时 / `No solution found`（如 `only anthropic<=2.10.0 is available`） | 镜像没同步到新版本。脚本会按 清华 → 阿里云 → 官方 自动换源重试；想指定源就设 `UV_DEFAULT_INDEX=<地址>`（可以写多个，空格隔开） |
| 每次启动都重新安装 | 旧版 `start.sh` 和 `启动监控台.bat` 的「装过没有」判断不一样，交替用会互相触发重装。更新后两者共用 `installed.path` + `installed.pyproject` |
| 想彻底重装 | 删掉 `~/.guanzi-monitor/venv` 文件夹再启动（数据不受影响） |

## 运行

| 现象 | 原因与处理 |
|---|---|
| 浏览器打不开 / 打开是空白 | 看 `--status` 的 `url`，端口可能自动换了；`running:false` 看日志 |
| Windows 上用 `--bg` 启动，过一会就打不开（空白 / 502） | 在 AI 助手或终端里 `--bg` 起的进程，会随那个会话/窗口一起被关掉。Windows 长期用请双击 `启动监控台.bat`，并保留那个黑窗口（可以最小化） |
| 测试连接报 `CERTIFICATE_VERIFY_FAILED` / `unable to get local issuer certificate` | 旧版装出来的 Python 没带根证书（Windows 常见）。`git pull` 后重新启动，会自动补装 certifi 并用它的证书；公司网络有自己的证书时，设 `SSL_CERT_FILE=<证书文件>` |
| 一直停在欢迎页 | Monid Key 还没填或没保存 |
| 「保存位置不可用」 / 「外接盘没插」 | 设置过的保存位置不存在了；`start.sh --data ~/观自行深监控台` 改回默认 |
| 任务一直「排队中」 | 同时最多 3 个任务；看「任务记录」有没有卡住的，取消后重试 |
| 部分链接没采到 | 单条页下方「没采到的链接」有原因和「重试」按钮 |
| 图片显示不出来 | 平台图片链接过期了；在内容上点「刷新数据」 |
| 关键词结果没有作者主页 / 播放量 | 抖音指数不返回这些；播放量所有渠道都拿不到 |

## 接口报错

| 报错 | 处理 |
|---|---|
| 401 / 403 / invalid key | Key 填错或被删，重新复制粘贴 |
| 402 / BLOCKED / insufficient balance | 余额不足，去充值 |
| 502 / all providers failed | 上游临时故障，过几分钟重试；一直失败就在设置里切到 TikHub |
| 429 | 请求太快，等一分钟 |
| 转写 AccessDenied.Unpurchased | 百炼 Key 所在业务空间没开通语音识别 |
| 转写「拿不到可转写的音频」 | 冒号后面是每条取直链路线失败的原因：视频被删或设了权限、渠道临时故障（过几分钟重试）；视频号暂不支持 |
| 转写一直「转写中」 | 看任务日志最后一行停在哪一步（取直链 / 已提交阿里云 / 阿里云转写进行中）。重启监控台后，没跑完的会变成「失败」，可以重试 |

解决不了：把「任务记录」里那条任务的日志截图发给老师。
