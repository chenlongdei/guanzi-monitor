# 排错

先看两样东西：
```bash
bash "<skill>/scripts/start.sh" --status
tail -50 ~/.guanzi-monitor/server.log
```
Windows：`%USERPROFILE%\.guanzi-monitor\server.log`（前台运行时日志直接在黑窗口里）。

## 安装

| 现象 | 原因与处理 |
|---|---|
| Mac 双击 `.command` 提示「无法打开，来自身份不明的开发者」 | 右键 → 打开 → 再点「打开」；或终端运行 `xattr -dr com.apple.quarantine <skill 文件夹>` |
| 卡在「安装 uv」 | 访问不了 astral.sh。Mac 改用 `python3 -m pip install --user uv -i https://mirrors.aliyun.com/pypi/simple/`；Windows 改用 `py -m pip install --user uv -i https://mirrors.aliyun.com/pypi/simple/`（需要先装 Python） |
| 卡在下载 Python | 脚本默认走 npmmirror 镜像；公司网络拦截时换个网络，或先自己装 Python 3.11+，uv 会直接用 |
| 依赖下载慢 / 超时 | 默认走阿里云 PyPI 镜像；可以设 `UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple` 再试 |
| 想彻底重装 | 删掉 `~/.guanzi-monitor/venv` 文件夹再启动（数据不受影响） |

## 运行

| 现象 | 原因与处理 |
|---|---|
| 浏览器打不开 / 打开是空白 | 看 `--status` 的 `url`，端口可能自动换了；`running:false` 看日志 |
| 一直停在欢迎页 | Monid Key 还没填或没保存 |
| 「保存位置不可用」 / 「外接盘没插」 | 设置过的保存位置不存在了；`start.sh --data ~/观自行深监控台` 改回默认 |
| 任务一直「排队中」 | 同时最多 3 个任务；看「任务记录」有没有卡住的，取消后重试 |
| 部分链接没采到 | 单条页下方「没采到的链接」有原因和「重试」按钮 |
| 图片显示不出来 | 平台图片链接过期了；在内容上点「刷新数据」 |
| 关键词结果没有作者主页 / 播放量 | 抖音指数不返回这些；播放量所有渠道都拿不到 |

## 接口报错

| 报错 | 处理 |
|---|---|
| 401 / 403 / invalid key | Key 填错或被删，重新复制粘贴 |
| 402 / BLOCKED / insufficient balance | 余额不足，去充值 |
| 502 / all providers failed | 上游临时故障，过几分钟重试；一直失败就在设置里切到 TikHub |
| 429 | 请求太快，等一分钟 |
| 转写 AccessDenied.Unpurchased | 百炼 Key 所在业务空间没开通语音识别 |
| 转写「拿不到可转写的音频」 | 视频被删或设了权限；视频号暂不支持 |

解决不了：把「任务记录」里那条任务的日志截图发给老师。
