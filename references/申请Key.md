# 申请 Key

监控台本身免费，采集用的是第三方数据接口，按次付费，钱直接付给接口方，每个人用自己的账号。

## 1. Monid（必需）

负责从抖音、小红书、视频号拿内容和数据。

1. 打开 https://app.monid.ai ，用邮箱或 Google 账号注册
2. 充值：$5 一般够一个人用一两个月（见 `费用.md`）
3. 在控制台找到 API Key，复制以 `monid_live_` 开头的那一串
4. 粘到监控台「欢迎」页第 1 步（或「设置」→ Monid Token），点「保存并测试」，看到余额就成功了

## 2. 阿里云百炼（可选，转逐字稿用）

1. 打开 https://bailian.console.aliyun.com/ ，用阿里云账号登录（没有就用手机号注册、实名）
2. 开通「模型服务」，新用户有免费额度
3. 左侧「API-KEY」→ 创建，复制以 `sk-` 开头的 Key
4. 粘到「欢迎」页第 2 步（或「设置」→ 阿里云百炼 Key），点「测试」

测试报「没开通 Paraformer 语音识别」：说明这个 Key 所在的业务空间没开通语音识别，用默认业务空间的 Key，或在模型广场里开通 paraformer-v2。

## 3. TikHub（可选，备用通道）

Monid 偶尔不稳时可以切过去。https://user.tikhub.io 注册充值，复制 API Token，粘到「设置」→ TikHub Token，再把「采集用哪家」切到 TikHub。

## 安全

- Key 只保存在你自己电脑上的数据库里，不会上传到任何地方
- 不要把 Key 发到群里或截图外传；泄露了就去对应网站删掉重建
